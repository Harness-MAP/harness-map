# cand_r035_0_spatial-grounding — IN-EPISODE VALUE LEARNER

## axis:
Code: where the decision is made. The parent asks the model on every turn and passes its reply
through a regex. Here a per-episode learner chooses each move. It keeps optimistic action values
per square, and an eligibility trace credits those values with a reward read from the frame. The
model is asked only to break ties, once per square. `tools/` is gone: `agent.py` holds
`build_agent`, the hub `LearnerAgent`, `decide_action`, and `parse_glyph_map` -> `clause_index`.

## change:
Every step runs in this order:
1. Reflexes: a `[yn]` attack prompt gets `y`, `--More--` gets `more`, and any other open prompt
   gets `esc`. On a remembered `>` (or "staircase down here"), emit `down`.
2. Credit the last move. Reward = +0.05 per newly drawn cell (capped at 10), +0.5 for standing on
   an unstood square, -1 for a no-move bump (that (square, move) is pinned to -1), and +0.4 per
   step closer to a drawn `>`. The TD error is pushed back along the trace (alpha 0.5, gamma 0.9,
   lambda 0.8), so the move that STARTED a productive corridor gets paid too.
3. Lava/water named in the adjacent prose, or a `}` next to the hero, removes that bearing.
   A letter on an adjacent square is swung at.
4. Rank the safe moves by value + 0.6/sqrt(1+tries), ties broken by a fixed bearing order.
5. If two or more moves are within 0.05 of the top on a square not yet consulted, show the model
   the stock history with the tied moves named, and project its reply onto them.
All state clears on `reset()` and when `Dlvl` changes. Each emission writes its rung to
`reasoning`.

## why:
Diagnosis iter 0: a memoryless frame->action map locked into period-2 orbits (38% reversals),
bumped walls (28% no-move), walked into named lava, and froze on `[yn]`. The values make a bump
self-extinguishing, the optimism makes untried moves win over tried ones, and the trace pays
whole corridors rather than one step. This is a learned policy, not a chart and search route.
On a stub 11x11 maze with a random model the learner reached `>` 20/20 (median ~90 steps,
16 model calls).
