## HARNESS STATE — derived by the harness from its own executed moves, never from the cube

- step: {{step}}
- moves executed so far (most recent last): {{played}}
- reduced move word: {{word}}
- distinct configurations stood on: {{stood}}
- screen: {{screen}}
- REFUSED this turn: {{refused}}
- ALLOWED this turn: {{allowed}}

The reduced word cancels only true identities — a turn immediately followed by its inverse, and
four quarter turns of one face — so two prefixes that reduce to the same word really are the same
cube. A refused turn is one the harness can prove wastes the step.

Name one ALLOWED action. If you name a refused one the harness substitutes the first allowed
action and the step is spent anyway, so a refusal is a step you chose not to use.
